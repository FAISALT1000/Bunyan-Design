# Bunyan Storybook Showcase

This Expo application runs the stories distributed with the local
`@bunyan/design-system` package.

## Requirements

- Node.js 20.19.4 or newer
- Xcode for iOS, Android Studio for Android, or a modern browser for web

## Run

```bash
nvm use
npm install
npm run ios
```

Other targets:

```bash
npm run android
npm run web
```

If Bunyan source or stories change, refresh the local package copy:

```bash
npm install
```
